# 🏢 Human Resource Management System (HRMS)

A Spring Boot based Human Resource Management System (HRMS) developed using industry-standard architecture and best practices.

This project is being developed module by module with clean architecture, DTO pattern, MapStruct, Validation, Exception Handling and REST APIs.

---

## 🚀 Tech Stack

- Java 21
- Spring Boot 3
- Spring Data JPA
- Hibernate
- PostgreSQL (Neon DB)
- Maven
- MapStruct
- Lombok
- Swagger / OpenAPI
- Jakarta Validation
- Git & GitHub
